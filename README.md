# Taş Fırın Lovemacun – Menü

    npm install
    npm run dev      # geliştirme
    npm run build    # dist/ klasörü yayına hazır

- Menü ve fiyatlar: `src/menu.js`
- Hero görseli: `public/hero.jpg` koy (yoksa renkli arka plan görünür)
- Ürün görseli: `public/img/` içine at, menu.js'de ürüne 4. değer olarak '/img/dosya.jpg' ekle
- QR: yayın adresi, masaya özel: `https://alanadin.com/?masa=5`

## Video ve animasyon
- Açılış videosu: `public/hero.mp4` koy (sessiz, 5-8 sn, 3-5 MB). Yoksa fotoğraf slayt gösterisi görünür.
- Duman/buhar animasyonları kod ile yapılır (açılışta yükselen duman, kartlarda buhar), ek dosya gerekmez.
